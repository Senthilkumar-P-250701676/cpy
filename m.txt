============================================================
1. PYTHON BASICS
============================================================

print(...)
    Displays text, values, or results.

input("prompt")
    Reads text entered by the user. Convert it with int(...) or float(...) when needed.

int(value)
    Converts a value to an integer when possible.

float(value)
    Converts a value to a floating-point number.

str(value)
    Converts a value to a string.

len(object)
    Returns the number of items in an object.

range(start, stop, step)
    Generates a sequence of integers. The stop value is excluded.

format(...)
    Inserts values into a formatted string. Example: "Value: {}".format(x).

type(object)
    Returns the object's type.

list(iterable)
    Creates a list from an iterable.

enumerate(iterable)
    Iterates over items while also providing their index.

2. NUMPY (import numpy as np)
============================================================

np.array(data)
    Creates a NumPy array from a list or other sequence.

np.arange(start, stop, step)
    Creates values in a range; stop is excluded.

np.zeros(shape)
    Creates an array filled with zeros.

np.ones(shape)
    Creates an array filled with ones.

np.random.rand(...)
    Generates random values from a uniform distribution between 0 and 1.

np.random.randint(low, high, size)
    Generates random integers; high is excluded.

np.random.normal(loc, scale, size)
    Generates random values from a normal distribution.

np.mean(array)
    Calculates the mean.

np.median(array)
    Calculates the median.

np.std(array)
    Calculates standard deviation.

np.min(array) / array.min()
    Returns the minimum value.

np.max(array) / array.max()
    Returns the maximum value.

np.percentile(array, q)
    Returns the value at percentile q (for example, q=25 or q=75).

np.unique(array)
    Returns unique values.

np.isnan(array)
    Identifies NaN (missing numeric) values.

np.where(condition, x, y)
    Selects x where condition is true and y otherwise.

np.concatenate((a, b), axis=...)
    Joins arrays along an existing axis.

np.vstack((a, b))
    Stacks arrays vertically (row-wise).

np.hstack((a, b))
    Stacks arrays horizontally.

np.dot(a, b)
    Computes a dot product / matrix product where dimensions allow.

a @ b
    Operator for matrix multiplication.

array.reshape(shape)
    Changes an array's shape without changing its data when possible.

array.shape
    Attribute showing array dimensions.

array.dtype
    Attribute showing array data type.

array.T
    Attribute returning the transpose.

np.save(filename, array)
    Saves a NumPy array to a .npy file.

np.load(filename)
    Loads an array saved in a .npy file.

np.nan
    Special value used to represent a missing numeric value.

np.nanmean(array)
    Calculates the mean while ignoring NaN values.

pd.read_csv(filename)

pd.DataFrame(data)

df.duplicated()

df.drop(columns=[...])

df.set_index(column)

df.rename(columns={old: new})

df.value_counts()

df.unique()

df.nunique()

df.replace(old, new)

df.apply(function)

df.map(mapping_or_function)

6. PYTHON / DATA CLEANING EXPRESSIONS
============================================================

condition
    A Boolean expression such as df['Age'] < 0.

(df['Age'] < 0) | (df['Age'] > 100)
    | means element-wise OR for pandas/NumPy conditions.

(condition1) & (condition2)
    & means element-wise AND for pandas/NumPy conditions.

~condition
    Element-wise NOT; commonly used to invert a Boolean mask.

df.loc[condition, 'column'] = np.nan
    Replaces values matching a condition with NaN.

array[(array > lower) & (array < upper)]
    Boolean filtering: keeps values satisfying both conditions.

IQR = Q3 - Q1
    Interquartile range; Q1 is the 25th percentile and Q3 is the 75th percentile.

lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
    Common IQR rule for flagging potential outliers.

============================================================

from sklearn.impute import SimpleImputer

    Creates an imputer that replaces missing numeric values with the mean.

SimpleImputer(strategy='median')

imputer.fit(data)
    Learns replacement statistics from data.

imputer.transform(data)
    Applies the learned replacement to data.

imputer.fit_transform(data)
    Learns replacement statistics and transforms data in one step.

from sklearn.preprocessing import OneHotEncoder
OneHotEncoder(sparse_output=False)
    Converts categorical values into one-hot columns. In older scikit-learn versions, sparse=False was used.

from sklearn.preprocessing import StandardScaler
StandardScaler()
    Creates a scaler that standardizes features using learned mean and standard deviation.

from sklearn.preprocessing import MinMaxScaler
MinMaxScaler(feature_range=(0, 1))
    Creates a scaler that maps features to a chosen range, usually 0 to 1.

scaler.fit(data)
    Learns scaling parameters from data.

scaler.transform(data)
    Applies the learned scaling parameters.

scaler.fit_transform(data)
    Learns parameters and scales data in one step.

15. COMMON OPERATORS / ATTRIBUTES USED IN THE LAB
============================================================

=
    Assignment operator.

==
    Equality comparison.

<, >, <=, >=, !=
    Comparison operators.

+, -, *, /, **
    Arithmetic operators; ** means exponentiation.

:
    In slicing, selects a range. Example: df.iloc[:, 0] selects all rows of column 0.

-1 in slicing
    Often means the last position. Example: df.iloc[:, :-1] selects all columns except the last.

.values
    Converts a pandas selection to a NumPy array.

.inplace=True
    Requests that a pandas operation modify the object rather than return a separate result. Some newer pandas patterns prefer assignment instead.

.fill_amount / .shape / .dtype / .columns / .coef_ / .intercept_ / .inertia_
    These are attributes or properties, not functions; they are accessed without parentheses.
